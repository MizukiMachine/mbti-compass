# Shadow Friend（関係摩擦マップ）

自分のMBTI傾向を診断し、周囲にいそうな人物プリセットを選びながら、相手ごとの摩擦、距離感、会話方針をシミュレーションするアプリです。

MBTIは相手を断定するためではなく、自分と相手の関係で起きやすい摩擦を眺める補助情報として扱います。

## 機能

- **自分診断** — 20問（4軸×5問）で自分のMBTI傾向を判定
- **関係摩擦マップ** — 中心に自分、周囲に気になる人物プリセットを配置
- **人物プリセット** — 「正論で詰めてくるけど責任感が強い先輩」「距離感が近すぎるけど孤立を放っておけない友人」など、関係で起きる摩擦名から選択
- **カテゴリ** — 職場、友人、恋愛、家族、苦手な相手、コミュニティ
- **関係メモ** — 相手ごとに信頼度、心理的負荷、メモを調整
- **相談アクション** — 信頼構築、頼みごと、断り方、伝えにくいこと、関係修復、距離の取り方、雑談、大事な話の準備
- **実用アウトプット** — 方針、避けたい言い方、文面ドラフト、会話の切り出し、次の一手を生成
- **ローカル保存** — 診断結果と関係マップをブラウザに保存

## 体験フロー

1. 名前を任意入力して自分診断を始める
2. 診断結果を中心にした関係摩擦マップへ移動
3. 気になる人物プリセットを選ぶ
4. 起きやすい摩擦、隠れた欲求、信頼の作り方、地雷を読む
5. 「頼みごとをする」「距離を置く」「ちゃんと話す準備」などの相談アクションを選ぶ
6. AIが方針、NG表現、文面ドラフト、次の一手を返す

## 技術スタック

| レイヤー | 技術 |
|---|---|
| フロントエンド | Next.js 14, React 18, Tailwind CSS, Framer Motion |
| LLM | GLM-5-turbo（Z.ai / Anthropic互換API） |
| 永続化 | localStorage（診断結果・関係マップ） |
| テスト | Jest |

## 環境変数

| 変数名 | 必須 | 説明 |
|---|---:|---|
| `ANTHROPIC_API_KEY` | No | 設定すると相談回答にLLMを使用。未設定時はフォールバック回答 |
| `LLM_MODEL` | No | デフォルト: `glm-5-turbo` |
| `LLM_BASE_URL` | No | デフォルト: `https://api.z.ai/api/anthropic` |
| `LLM_TIMEOUT_MS` | No | デフォルト: `10000` |

Supabase関連の認証ファイルは旧実装の名残として残っていますが、現在のMVPでは診断結果と関係マップはlocalStorageに保存します。

## 注意

相手のMBTI候補は観察情報からの仮説です。実在の人物を断定・分類する目的ではなく、伝え方や距離感を考えるための補助として使います。
