# Shadow Friend（関係摩擦マップ）

自分のMBTI傾向を診断し、周囲にいそうな人物プリセットを選びながら、相手ごとの摩擦・距離感・会話方針をシミュレーションするWebアプリ

MBTIは相手を断定するためではなく、自分と相手の関係で起きやすい摩擦を眺める補助情報として扱う

## アプリ概要

- **自分診断** — 4軸（EI / SN / TF / JP）×5問の計20問で自分のMBTI傾向を判定
- **関係摩擦マップ** — 中心に自分、周囲に気になる人物プリセットを配置したキャンバス
- **人物プリセット** — 「正論で詰めてくる先輩」「空気を読みすぎる同僚」など、関係で起きる摩擦名から選択
- **カテゴリ** — 職場 / 友人 / 恋愛 / 家族 / 苦手な相手 / コミュニティ
- **関係メモ** — 相手ごとに信頼度・心理的負荷・自由メモを調整
- **相談アクション** — 信頼構築・頼みごと・断り方・フィードバック・関係修復・距離の取り方・雑談・大事な話の準備
- **実用アウトプット** — 方針・避けたい言い方・文面ドラフト・会話の切り出し・次の一手を生成
- **ローカル保存** — 診断結果と関係マップをブラウザの `localStorage` に保存

## アプリの仕様と挙動

### 体験フロー

1. 名前を任意入力して自分診断を開始
2. 20問の回答後にMBTIタイプが確定し、関係摩擦マップへ遷移
3. マップ上の人物スロットからプリセットを選択
4. 相手の摩擦特性・隠れた欲求・信頼の作り方・地雷を確認
5. 相談アクションを選ぶと、LLMが方針・NG表現・文面・次の一手を返す
6. APIキー未設定時はフォールバック回答を表示

### 相談アクション一覧

| アクション | 内容 |
|---|---|
| 信頼関係を作る | 信頼を築くための接し方と最初のステップ |
| 頼みごとをする | 通りやすい頼み方の構成と文面 |
| 断る | 関係を壊さない断り方 |
| フィードバックする | 伝えにくい指摘の切り出しと構成 |
| 関係を修復する | すれ違い後の修復アプローチ |
| 距離を置く | 心理的距離の取り方 |
| 雑談する | 話題の選び方と空気の作り方 |
| 1on1に備える | 大事な話の準備と構成 |

### LLM相談API

- `POST /api/workplace/advice` に `selfMbti` / `person` / `actionId` / `userConcern` を送信
- APIキー未設定時はフォールバック回答を返す（オフライン動作可能）

## 構成

```text
app/
├── app/
│   ├── page.tsx                         # 自分診断の入口（ランディング + 診断フォーム）
│   ├── explore/
│   │   ├── page.tsx                     # 関係摩擦マップ画面
│   │   ├── WorkplaceMapCanvas.tsx       # 中心に自分、周囲に人物プリセットを配置
│   │   └── RelationshipPanel.tsx        # 人物詳細・相談アクション・回答表示
│   └── api/workplace/advice/route.ts    # 相談アドバイス生成API
├── src/
│   ├── data/
│   │   ├── mbti-questions.ts            # 自分診断の質問データ
│   │   ├── workplace-presets.ts         # 人物プリセットと相談アクション
│   │   ├── trait-cards.ts               # MBTI特性カード
│   │   ├── mbti-characters.ts           # MBTIキャラクター定義
│   │   └── function-characters.ts       # 認知機能キャラクター
│   ├── lib/
│   │   └── workplace-advice.ts          # LLMプロンプトとフォールバック回答
│   └── types/
│       └── workplace.ts                 # 関係マップ関連の型定義
docs/
```
